The problem

One Anvil per agent doesn't scale.

Each agent runs its own process with its own cache. Cold, each fetches the same state.
How forkyard solves it

One process. Many sessions.

fork() is a pointer copy onto one shared, warm cache.

Architecture

Rust, end to end.

Three surfaces

MCP · stdio
MCP · HTTP :8556
JSON-RPC :8555

Sessions

crates/session

TTL lifecycle, sharded over worker threads. Jobs park on upstream reads instead of blocking.

Shared state + revm

crates/engine

Structurally shared map, O(1) fork. revm embedded in-process.

Lazy fetch

crates/fetch · ingest

Built on foundry-fork-db, plus forkyard's own batching. Warm disk cache when pinned, or follows the tip.

One process. One warm cache. Many isolated sessions.
